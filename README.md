# Landing Page Project

A simple landing page built as part of **The Odin Project – Foundations**.

## Purpose
The goal of this project was to practice **layout structure** and **Flexbox** by recreating the provided desktop‑focused design.  
It’s not intended to be fancy or responsive yet — the focus is on keeping things clean, readable, and close to the mockup.

## What I Practiced
- Semantic **HTML structure** with clear sections (`header`, `main`, `section`, `footer`)
- **Flexbox** for layout (header, hero, cards, CTA)
- Basic **CSS styling** (colors, typography, spacing)
- **Git workflow** (commit early & often)

## Notes
This project is part of my learning path, so I kept it simple and focused on fundamentals.  
If you’re checking it out, feel free to be kind — and enjoy exploring!
